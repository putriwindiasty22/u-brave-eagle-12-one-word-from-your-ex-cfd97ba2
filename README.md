One word, the word my ex would use to describe me: **avoidant**. Not cruel, not dramatic — just the quiet truth. Every unanswered text, every "let's talk later" that never came, every feeling filed away for a someday that never arrived, distilled into eight letters. It stings because it is true, and I know it.

## Run it

```sh
node main.ts
```

The program validates the word (exactly one word, 1–24 characters, letters only), writes it to `/output/entry.txt` — or `./output/entry.txt` when run locally — then reads it back and verifies the text and byte length match.
